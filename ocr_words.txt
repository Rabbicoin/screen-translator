# Слова, которые программа знает «в лицо».
#
# Зачем. Заглавные латинские и русские буквы — одни и те же значки: H и Н, T и Т,
# A и А, C и С, O и О, B и В. Распознавание выбирает алфавит наугад, и «Всего»
# становится «Bcero», «без НДС» — «6e3 HOC», «АКПП» — «AKNN». Если слово есть в
# этом списке, программа узнаёт его по форме значков и возвращает как надо.
#
# Как пополнять. Одно слово в строке, регистр любой. Строки, начинающиеся с
# решётки, — пояснения, программа их пропускает. Файл перечитывается на лету:
# сохранили — и следующий снимок уже с новым словом, перезапуск не нужен.
#
# Осторожно: слово из этого списка подменяет собой похожее по форме, поэтому
# короткие слова из двух-трёх букв добавлять не стоит — под них подойдёт слишком
# многое. Замена срабатывает только тогда, когда прочитанное слово написано не
# той письменностью, что преобладает в строке: на английской странице русские
# слова из списка не всплывут.
